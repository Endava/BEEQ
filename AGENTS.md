# AGENTS.md

BEEQ is a StencilJS web component library and design system, in an Nx monorepo. Components live in `packages/beeq`, design tokens and the Tailwind preset in `packages/beeq-tailwindcss`, framework wrappers in `packages/beeq-{angular,react,vue}`, consumer agent skills in `packages/beeq-skills`, and the Mintlify docs in `apps/beeq-docs`.

## Package manager and commands

Use `pnpm` (not npm). Nx projects are tagged `core`, `publishable`, `wrapper`, `preset`, `skills`; the filters below select by tag.

```bash
pnpm exec nx affected -t check --exclude='*,!tag:core' --parallel=3      # lint + typecheck
pnpm exec nx affected -t test --exclude='*,!tag:core' --parallel=3       # unit tests
pnpm exec nx affected -t e2e --exclude='*,!tag:core' --parallel=3        # e2e tests
pnpm exec nx affected -t build --exclude='*,!tag:publishable' --parallel=3
pnpm g                           # scaffold a component (Plop)
pnpm skills:sync                 # regenerate skills/ from beeq-skills/src
```

`pnpm build:beeq:fast` and `pnpm test:e2e:fast` skip icon generation; read [build performance](.agents/instructions/build-performance.instructions.md) before using them.

## Rules for every task

- Format and lint with Biome.
- Write commits as Conventional Commits (commitlint enforces them) and end docs-only commits with `[ci skip]`. Details: [git workflow](.agents/instructions/git-workflow.instructions.md).
- `CHANGELOG.md` is generated by Nx release; never edit it.
- Edit `packages/beeq-skills/src`; `skills/` is generated by `pnpm skills:sync`.
- Keep changes scoped to the task. Report refactors that would clearly improve performance, scalability, efficiency or readability as a final list: file, benefit, rough effort.

## Guidelines by task

Open the files for your task before editing. `applyTo` frontmatter in them is a hint for tools that support it; rely on these links. Package folders have their own `AGENTS.md` with local notes.

- **Editing a component (`.tsx`, `.scss`)**
  - [Components](.agents/instructions/components.instructions.md): structure, naming, JSDoc
  - [Styles](.agents/instructions/styles.instructions.md): required for any `.scss` change
  - [Accessibility](.agents/instructions/accessibility.instructions.md): ARIA, keyboard, contrast, WCAG 2.1 AA
- **Writing tests**
  - [Testing](.agents/instructions/testing.instructions.md): e2e for components, unit for `shared/`
- **Writing or editing docs in `apps/beeq-docs`**
  - [Documentation](.agents/instructions/documentation.instructions.md): tone, frontmatter, non-component pages
  - [Component docs](.agents/instructions/component-docs.instructions.md): component page structure
  - [Code examples](.agents/instructions/code-examples.instructions.md): `CodeLivePreview`, CSS tab, framework tabs
- **Committing, branching, opening a PR**
  - [Git workflow](.agents/instructions/git-workflow.instructions.md): branches, commits, PRs, breaking changes
- **Building or running e2e locally**
  - [Build performance](.agents/instructions/build-performance.instructions.md): `BEEQ_SKIP_ICONS` and `:fast` scripts
