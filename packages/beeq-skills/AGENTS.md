# packages/beeq-skills

Source, tests and evals for the consumer agent skills published to users of BEEQ. Read [README.md](README.md) for the full workflow.

- Edit `src/` only. The root `skills/` folder is generated by `pnpm skills:sync` and committed with the source change.
- Run `pnpm skills:test` after editing. The sync check, link check and frontmatter check run in CI.
- `apps/beeq-docs/skill.md` is a hand-written pointer; its frontmatter must match `src/beeq/SKILL.md`.
- Contributor-only skills live in `.agents/skills/` with `metadata.internal: true`; do not move them here.
