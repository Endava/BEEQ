# packages/beeq

The BEEQ component library (StencilJS). Components live in `src/components/<name>/`; shared utilities and test helpers in `src/shared/`.

- Scaffold new components with `pnpm g`; see the [components](../../.agents/instructions/components.instructions.md) and [styles](../../.agents/instructions/styles.instructions.md) guidelines.
- Component behavior is covered by e2e tests, shared utilities by unit tests; see the [testing](../../.agents/instructions/testing.instructions.md) guidelines.
- Build, test and e2e run through Nx (`beeq:build`, `beeq:test`, `beeq:e2e`). Icon generation runs before the build; read [build performance](../../.agents/instructions/build-performance.instructions.md) before skipping it.
- Angular, React and Vue wrapper proxies in `packages/beeq-{angular,react,vue}` are generated by the Stencil build. Do not edit them by hand.
