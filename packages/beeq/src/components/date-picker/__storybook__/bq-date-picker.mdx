    <Title>Date picker</Title>

    Stencil-native rewrite of the Date Picker component (no Cally dependency). Same public API and wire format as `bq-date-picker` — additional controls include `initial-view` (open the calendar directly on months or years) and a fully Intl-driven header.

    <Subtitle>Wire format</Subtitle>

    The shape of `value` depends on `precision` first, then on `type`:

    - `precision="day"` (default): tokens use `YYYY-MM-DD`
    - `precision="month"`: tokens use `YYYY-MM`
    - `precision="year"`: tokens use `YYYY`

    Those tokens are combined by `type`:

    - `single`: one token
    - `multi`: space-separated tokens
    - `range`: `start/end`

    Example values:

    - `day` range: `2026-05-15/2026-05-30`
    - `month` range: `2026-05/2026-08`
    - `year` multi: `2024 2026 2028`

    The input uses a fixed, locale-derived numeric mask. Its separators remain in place while users replace date segments. Numeric `formatOptions` control field order and separators; textual or variable-length options fall back to the locale numeric mask with a development warning.
